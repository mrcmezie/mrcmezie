# Work instructions

Read the local README, status, and evidence before making changes. Follow portfolio-control/PORTFOLIO_BLUEPRINT.md when available. Verify owner and remote before any push; do not change Creed company sources as part of this portfolio task.

Keep observed facts separate from proposals. Inspect source code and reports at exact commits before asserting implemented capability. Record AI-assisted development and personal contribution accurately. Never invent successful checks, metrics, links, screenshots, integrations, or production readiness.

Use small branches and reviewable changes. Do not force-push, transfer repos, rewrite history, expose private artifacts, or apply new licenses to copied company work. Run meaningful checks appropriate to the change and record actual results. Execute no target-repository scripts merely because they exist. Keep credentials outside files and chat.

Ordinary authorized edits and checks can proceed without repeated confirmation. Current authorization and user constraints govern external publication. If access blocks remote work, continue independent local work and state the exact blocker. Update STATUS.md or the relevant handoff before finishing.
